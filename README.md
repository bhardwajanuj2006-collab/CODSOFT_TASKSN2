Iris Classification
About the Project

This project uses machine learning to classify Iris flowers into three species: Setosa, Versicolor, and Virginica.

Dataset

The dataset contains flower measurements such as:

Sepal length
Sepal width
Petal length
Petal width
Technologies Used
Python
Pandas
NumPy
Matplotlib
Scikit-learn
Steps
Load the Iris dataset.
Explore and prepare the data.
Train a machine learning model.
Test the model.
Predict the Iris flower species.
Objective

To learn how machine learning can classify flowers based on their measurements.
